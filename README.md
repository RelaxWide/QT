# QT — Quant Swing Trading System

일목균형표 · 거래량 · 추세선 기반 스윙 자동매매 시스템

---

## 프로젝트 목표

- 기술적 분석 지표(일목균형표, 거래량, 추세선)를 조합한 **규칙 기반 스윙 매매 전략**을 코드로 구현
- **백테스트 모드**로 전략 유효성 검증 → **실전 매매 모드**로 전환 가능한 구조
- 완전 자동매매 / 반자동(알림 후 수동 체결) 중 선택적으로 운용

---

## 대상 시장 및 종목 필터

| 항목 | 기준 |
|------|------|
| 첫 번째 시장 | 미국 주식 (S&P 500 대형주) |
| 향후 확장 | 국내 주식(코스피 대형주), 암호화폐(BTC/ETH) |
| 공통 필터 | 시가총액 상위 / 유동성 충분 / 고변동 소형주 제외 |

---

## 핵심 전략 개요

### 1. 일목균형표 — 매집 포인트 탐지

- 일봉 기준 **5~10일 앞에 두꺼운 구름대(선행스팬 A/B 격차 큰 구간)** 존재 시 매집 시작
- 가격이 구름대에 닿았을 때 **지지 반등**을 기대하며 포지션 유지
- 구름 두께 기준: 추후 백테스트로 수치 정의 예정

### 2. 거래량 — 시그널 신뢰도 판단

- 허위 시그널 필터: 돌파/반등 시 거래량이 평균 이하이면 신뢰도 낮음
- 홀딩 vs 손절 판단 보조: 추세 유지 중 거래량 감소 = 약화 신호

### 3. 추세선 / 채널 — 경계 반등·이탈 판단

- 볼린저 밴드와 유사하게 채널 상·하단 경계를 계산
- 하단 터치 후 반등 = 매수 기회 / 상단 돌파 후 되돌림 = 매도 기회
- 추세선 이탈 시 손절 판단 트리거로도 활용

## 매매 규칙

### 진입

| 항목 | 규칙 |
|------|------|
| 기준 타임프레임 | 일봉 + 주봉 (멀티 타임프레임) |
| 분할 매수 | 최대 3회 (구름대 접근 구간 내) |
| 1회 진입 한도 | 총 자본의 10% 이내 |
| 동시 보유 한도 | 최대 10개 종목 |

### 청산

| 유형 | 기준 |
|------|------|
| 익절 | 추세 유효 시 연장 보유 / 채널 상단 도달 시 부분 청산 고려 |
| 손절 | 전략 로직의 손절 포인트 이탈 (추세선 + 거래량 + 구름대 이탈 조합) |
| 보유 기간 | 수일 ~ 1개월, 상황에 따라 유동적 |

## 운용 모드

```
[백테스트 모드]  →  전략 파라미터 튜닝 및 성과 검증
        ↓
[반자동 모드]    →  시그널 감지 + 알림 → 영웅문 글로벌에서 수동 체결
        ↓
[자동매매 모드]  →  시그널 감지 → API 자동 주문
```

## 기술 스택 (예정)

| 역할 | 도구 |
|------|------|
| 언어 | Python 3.11+ |
| 가격 데이터 | `yfinance` (미국주식) |
| 보조 데이터 | `pykrx` (국내), `ccxt` (암호화폐) |
| 백테스트 | 자체 구현 (추후 `vectorbt` 검토) |
| HTS 연동 | 영웅문 글로벌 (키움) — 반자동은 알림, 자동은 API 연동 검토 |
| 알림 | 텔레그램 봇 / 이메일 (미정) |

## 전략 로드맵

Phase 별로 진행하며, 각 Phase의 게이트(승률 ≥ 45%, PF ≥ 1.3, MDD ≤ 15%, Sharpe ≥ 0.8 등)를 통과해야 다음 Phase로 진행. 상세는 [STRATEGY.md](STRATEGY.md), Phase 1 실행 스펙은 [docs/PHASE1.md](docs/PHASE1.md) 참조.

1. **Phase 1** — Breakout Pullback 베이스라인 백테스트
2. **Phase 2** — 박스권 + 상승 구름 상단 지지 셋업 백테스트
3. **Phase 3** — Phase 1·2 통계 비교 기반 Hybrid 설계
4. **Phase 4** — 모멘텀·변동성 수축·상대강도 Factor Stacking
