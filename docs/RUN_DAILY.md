# run_daily.py 동작 설명

매일 미국 장 마감 후 한 번 실행하는 스크립트. S&P500 전 종목을 스캔해서 신호를 찾고, 보유 포지션을 관리하고, 결과를 텔레그램으로 알림.

---

## 실행 흐름 (순서대로)

### 0. 장 마감 확인
미국 동부시간(ET) 기준으로 장 중(09:30~16:00)이면 실행을 거부한다.  
장 중 데이터는 오늘 봉이 완성되지 않아 스톱/신호 판단이 부정확하기 때문.

```
python run_daily.py          # 장 마감 후 정상 실행
python run_daily.py --force  # 장 중 강제 실행 (테스트용)
```

---

### 1. 데이터 다운로드
S&P500 전 종목(약 500개)의 최신 일봉 데이터를 yfinance에서 받는다.  
`refresh=True`이므로 항상 오늘 날짜 데이터까지 새로 받음.  
지표 계산에 최소 300봉이 필요하므로 2015년부터 받는다.

---

### 2. 대기 진입 처리

어제 실행에서 "내일 진입 예정"으로 저장된 종목들을 처리한다.

**어제의 흐름**: 신호 발생 → `pending.json`에 저장  
**오늘의 흐름**: `pending.json` 읽기 → 오늘 시가로 진입 처리

진입 가격 = 오늘 시가 × (1 + 슬리피지 0.1%)  
수량 = (자본 × 0.7%) ÷ R  
R = 진입가 - 스톱가

처리 후 `positions.json`에 포지션 추가, `pending.json` 초기화.

**텔레그램 알림 예시**:
```
📈 진입 AAPL
  진입가: $185.20  스톱: $178.50
  R: $6.70  수량: 10.44주
```

---

### 3. 보유 포지션 청산 확인

`positions.json`의 모든 보유 종목에 대해 오늘 봉을 체크한다.  
우선순위: 스톱 → 목표가 → 트레일 순서로 확인.

#### 스톱 청산
오늘 저가(low) ≤ 현재 스톱가이면 스톱 청산.  
청산가 = 스톱가 × (1 - 슬리피지)

#### 목표가 도달 (부분 청산)
오늘 종가(close) ≥ 목표가이면 50% 부분 청산.  
부분 청산 후 **스톱을 진입가(본전)로 이동** → 이후 손실 없음.

#### 트레일 청산
목표가를 모두 소진한 잔여 포지션은 Donchian 10일 하한선 트레일.  
오늘 종가 < 트레일 기준선이면 청산.

청산된 거래는 `trades.csv`에 기록됨.

**텔레그램 알림 예시**:
```
✅ 청산 NVDA [stop]
  진입 $450.00 → 청산 $441.20
  R: -1.01R  PnL: $-67.20

🎯 부분 청산 MSFT
  목표 1 달성 @ $395.50
  스톱 → 본전($380.00)
```

---

### 4. 신규 신호 생성

오늘 봉 기준으로 Phase 4 전략 조건을 전 종목에 스캔.  
조건을 통과한 종목은 "내일 시가 진입 예정"으로 `pending.json`에 저장.

#### 진입 조건 (모두 충족 필요)
1. **돌파-풀백** (Phase 1): Donchian 20일 상단 돌파 후 풀백 + 양봉
2. **구름 위** (Phase 3): 종가 > 선행스팬A > 선행스팬B + 구름 두께 ≥ 2.5% + 전환선 > 기준선
3. **SPY 상대강도** (Phase 4): 최근 63일 수익률 > SPY 63일 수익률

레짐 필터: SPY < 50MA + VIX > 30이면 신호 있어도 진입 보류.  
최대 포지션 10개 초과 시 신호 있어도 진입 보류.

**텔레그램 알림 예시**:
```
🔔 신호 META (내일 시가 진입 예정)
  예상 진입: $520.30  스톱: $504.10
  R: $16.20  목표: $568.90
```

---

### 5. 현황 요약 & 텔레그램 발송

모든 처리가 끝난 뒤 오늘의 전체 현황을 취합해서 텔레그램으로 전송.

```
📊 Paper Trading 현황 [2026-04-20]
  보유: 3종목  |  대기: 1종목
  누적 거래: 12건  |  승률: 41.7%
  Profit Factor: 1.85  |  총 PnL: $+1,240.50
  레짐: ✅ 정상

보유 종목:
  AAPL: 진입 $185.20 | 현재 $191.40 | 미실현 $+64.73
  NVDA: 진입 $450.00 | 현재 $463.20 | 미실현 $+137.76
  MSFT: 진입 $380.00 | 현재 $388.50 | 미실현 $+44.65
```

## 관련 파일

| 파일 | 역할 |
|------|------|
| `paper_trading/positions.json` | 현재 보유 포지션 (스크립트가 매일 갱신) |
| `paper_trading/pending.json` | 내일 진입 예정 대기 목록 |
| `paper_trading/trades.csv` | 청산된 모든 거래 기록 (누적) |
| `config.yaml` | 전략 파라미터 + 텔레그램 토큰 |

---

## 주의사항

- **매일 실행해야 한다**: 하루 빠지면 그날 스톱/목표가 체크가 누락된다.
- **장 마감 후 실행**: 미국 동부시간 오후 4시 이후 = 한국 시간 새벽 5시 이후.
- **데이터는 종가 기준**: 스톱은 저가(intraday low) 기준, 신호/목표는 종가 기준.
- `positions.json`을 직접 편집하면 추적이 꼬일 수 있으므로 주의.
