## 용어 사전

### 수익성 지표
| 용어 | 설명 |
|---|---|
| **CAGR** | 연평균 복리 수익률. SPY B&H ~13.5% |
| **Profit Factor (PF)** | 총 이익 / 총 손실. 1.5 이상 권장 |
| **월별 승률** | 수익 마감 월 / 전체 월 수 |
| **Tail ratio** | 상위 5% 수익 / 하위 5% 손실 절댓값 비율. 1.0 이상 = 큰 수익이 큰 손실보다 큼 |

### 리스크 지표
| 용어 | 설명 |
|---|---|
| **MDD** | 최대 낙폭. 음수가 클수록 위험 |
| **Sharpe** | 리스크 대비 수익률. 1.0 이상 우수 |
| **Sortino** | 하방 변동성만 사용한 Sharpe |
| **Calmar** | CAGR / \|MDD\|. 0.5 이상 권장 |
| **Max losing streak** | 최대 연속 손절 횟수. 멘탈 부담 척도 |

### 트레이드 지표
| 용어 | 설명 |
|---|---|
| **WR** | 승률. 추세추종 30~40% 정상, 평균회귀 60~70% |
| **R** | 1R = 진입가 − 손절가 |
| **평균 승리 R** | 수익 트레이드 평균 R. 3R 이상 = 손익비 우수 |
| **평균 손실 R** | 손실 트레이드 평균 R. −1R에 가까울수록 손절 준수 |
