## 🔧 Phase 4-v2 — 일목구름 선접근 (Anticipatory Cloud) 개발 중

**컨셉**: 두꺼운 상승 구름을 3~7일 앞에서 미리 매수. 가격이 구름으로 하락해오는 도중 진입, 구름 상단에서 반등 대기.

**이상적인 셋업 특징 (FIS/LLY 패턴)**:
- 상승추세 종목이 두꺼운 주황색 구름(두께 4%+) 위에서 완만히 하락 중
- 구름 상단까지 3~12% 이격
- 2~7일 내 선형 외삽으로 구름과 만남 예측
- 구름 터치 후 반등 → 목표가 달성

**진입 필터 체계** (2026-05-06 기준 — 14개 조건):

| 조건 | 목적 |
|---|---|
| close > 현재 구름 상단 | 구름 밖에서 접근 확인 |
| 이격 3~12% | 너무 가깝거나 멀면 제외 (TPR형·FCX형 차단) |
| eta_min~eta_max 모든 봉 두꺼운 구름 (≥4%) | 구름 블록 전체 품질 확인 |
| slope < 0 (하락 중) | 위에서 아래로 접근 중 |
| slope > -1.5%/day | 자유낙하 제외 |
| 미래 구름 이격 ≤ 8% | 너무 먼 미래 만남 제외 |
| 최근 20봉 내 2% 이상 고점 | 눌림 확인 |
| 40봉 중기 추세 ≥ 0 | 하락추세 종목 제외 |
| 15봉 내 구름 터치 없음 | 두 번째 접근 방지 |
| 전환선 ≥ 기준선 + 1% | 눌림이지 반전 아님 |
| 후행스팬 양수 | 중기 상승 유지 |
| 50MA 위 + 50MA 상승 | 하락추세 종목 제외 |
| 저가 20봉 추세 상승 | 저점이 높아지는 패턴 |
| 다음날 시가 갭업 ≤ 2% | 갭업 진입 시 thesis 무의미화 방지 |
