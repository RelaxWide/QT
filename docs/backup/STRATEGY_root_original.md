# STRATEGY.md — 전략 상세 설계

> 이 문서는 QT 시스템의 전략 로직과 검증 로드맵을 정의한다.
> 핵심 원칙: **데이터가 말하게 한다** — 직관은 "가설"로 설정하고 백테스트로 검증, 결과에 따라 로직을 조정한다.

---

## 0. 설계 원칙

### 0.1 투자 성향 (본 프로젝트의 제약)
- 승률 우선, 정확한 손절, 멘탈 보호
- 모든 것을 예측하지 않음 — 확률이 유리한 셋업만 선택
- 손실은 **진입 전에 금액이 확정**되어야 함

### 0.2 엣지의 원천
- 전략 공식이 아니라 **실행의 일관성**
- 검증된 셋업 + 규율 있는 실행 + 체제 인식(regime awareness)
- 공개된 규칙이지만 감정·조급함·레버리지로 대부분이 실패 → 규율이 알파

### 0.3 검증 철학
- 가설 → 백테스트 → 페이퍼 트레이딩 → 실전(소액) → 본격 운용
- 각 단계에서 **실패 기준**을 사전 정의 (통과 못 하면 원인 분석 후 재설계)

## 1. 공통 리스크 프레임워크 (전 Phase 공통)

### 1.1 트레이드당 리스크 고정
```
risk_per_trade = 총자본 × 0.7%   (초기 보수 설정, 안정화 후 1%로 확대 검토)
position_size  = risk_per_trade / (entry_price − stop_price)
```
- 10연속 손절 = −7% 손실 (복구 가능 구간)
- 포지션 비중은 고정이 아니라 **손실 금액 기준으로 역산**

### 1.2 단일 가격 손절
- 진입 시점에 손절가를 **하나의 숫자로 확정**
- 복합 조건(A or B and C) 금지 — 주관 개입 여지 차단
- 손절가 도달 시 예외 없이 청산 (종가 기준)

### 1.3 포트폴리오 한도
- 동시 보유: 최대 7~10종목
- 단일 섹터 집중: 자본의 30% 이내
- 상관계수 0.7 이상 종목 페어 동시 보유 금지

### 1.4 서킷 브레이커
| 트리거 | 액션 |
|---|---|
| 일 손실 > 자본 1.5% | 당일 신규 진입 중지 |
| 주 손실 > 자본 3% | 주말에 로직 리뷰 |
| 월 낙폭 > 5% | 포지션 크기 50% 축소 |
| 누적 낙폭 > 10% | 전면 중단, 백테스트 재검증 |

### 1.5 시장 체제 필터
- SPY 50일선 하향 이탈 + VIX > 30 → 1주일간 신규 진입 금지
- SPY 200일선 아래 → 포지션 크기 50% 축소

## 2. 전략 로드맵

```
[Phase 1: Breakout Pullback (베이스라인)]
    → 검증된 고전 셋업으로 기준선 확보
          ↓
[Phase 2: Original Setup (박스권 + 상승 구름 상단 지지)]
    → 사용자 원 셋업을 동일 조건으로 백테스트
          ↓
[Phase 3: Hybrid]
    → Phase 1·2 통계 비교 → 우수 셋업 기반 + 보조 셋업
          ↓
[Phase 4: Factor Stacking]
    → 모멘텀·변동성 수축·상대강도 Confluence 필터
```

### Phase 게이트 (다음 단계 진행 최소 기준)
| 지표 | 최소 기준 |
|---|---|
| 샘플 수 | 100 트레이드 이상 |
| 승률 | 45% 이상 |
| Profit Factor | 1.3 이상 |
| 최대 낙폭 | 15% 이하 |
| Sharpe | 0.8 이상 |

게이트 미달 시: 다음 Phase 진행 금지, 원인 분석 후 셋업 재설계 또는 폐기.

## 3. Phase 1: Breakout Pullback (베이스라인)

### 3.1 가설
> "20일 신고가를 돌파한 종목이 돌파가까지 되돌림(throwback)한 후 재상승할 때, 추세 재개 확률이 유리하다."

### 3.2 진입 조건
- 일봉 종가가 **직전 20일 최고가**를 돌파 (Donchian 20 상단 돌파)
- 돌파 후 **1~5봉 이내**에 가격이 **돌파가 ± 0.5 × ATR20** 범위까지 되돌림
- 되돌림 중 저가가 돌파가를 훼손해도 **종가가 돌파가 위에서 마감** 시 유효
- 진입: 되돌림 이후 첫 양봉의 **다음 날 시가**

### 3.3 손절
```
stop = min(돌파 직전 최근 스윙로우, 진입가 − 2 × ATR20)
```

### 3.4 익절
- 1차 목표: 진입가 + 3R (= 리스크의 3배)
- 1차 도달 시 50% 부분 청산
- 나머지 50%: 10일 Donchian 하단 종가 이탈 시 청산 (트레일링)

### 3.5 유니버스 및 필터
- S&P 500 현 구성 종목
- 가격 > $10, 20일 평균 거래량 > 500K 주
- 공통 리스크 프레임워크(§1) 적용

### 3.6 백테스트 명세
- 기간: 2015-01-01 ~ 실행일
- 데이터: yfinance 일봉 (배당 조정 종가)
- 슬리피지: 체결가의 0.1%
- 수수료: $0 가정 (실전 시 영웅문 수수료 반영)
- 세금: 별도 계산 (한국 거주자 미국주식 양도세 22%, 공제 250만원/년)

## 4. Phase 2: 박스권 + 상승 구름 상단 지지

### 4.1 가설
> "가격이 두꺼운 상승 구름 위에서 박스권을 형성할 때, 구름 상단 지지 터치 후 반등이 빈발한다."

### 4.2 진입 조건
- 가격 > 선행스팬 A > 선행스팬 B (**상승 구름 위**)
- 후행스팬 > 26일 전 가격 (추세 확인)
- 구름 두께: `(선행스팬 A − 선행스팬 B) / 가격 ≥ X%` (TBD)
- 박스권: 최근 20봉 `(고가 − 저가) / 중간가 ≤ Y%` (TBD)
- 박스 내 되돌림으로 **저가가 구름 상단에 터치** (`저가 ≤ 선행스팬 A × 1.005`)
- **종가는 구름 위 유지**
- **R:R 필터**: 진입 시점에 `(박스 상단 − 평균 진입가) / R ≥ 1.0` 또는 트레일링으로 1.5R 이상 기대 가능해야 함. 미달 시 패스.

### 4.3 손절 — 단일 가격 고정
**추세 무효화 기준**: "가격 > 구름 상단" 명제가 깨지는 순간 = 종가 기준 선행스팬 A 하향 이탈.

```
stop = 선행스팬_A(진입일 고정값) − 0.5 × ATR20
```

- **트리거**: 일봉 종가 ≤ stop → 다음 날 시가 청산
- **왜 A 기준인가**: 구름 상단 지지가 가설의 핵심. 종가로 A 이탈 = 가설 소멸. B까지 기다릴 이유 없음.
- **왜 0.5×ATR 버퍼**: 장중 순간 이탈 노이즈 흡수 (종가 기준 + 추가 안전장치)
- **왜 진입일 고정값**: 선행스팬 A는 시간에 따라 변하므로, 진입 시점 값으로 stop을 **단일 가격으로 확정** (§1.2 원칙)

### 4.4 익절 — R-배수 기반 (기하 독립적)
```
R = 평균 진입가 − stop
목표 1: 평균 진입가 + 1.5R  → 50% 부분 청산 + stop을 평균 진입가(본전)으로 이동
목표 2: 평균 진입가 + 3.0R  → 추가 30% 부분 청산
잔여 20%: 전환선(9일) 종가 이탈 시 청산 (트레일링)
```

- **왜 1.5R + 본전 이동**: 박스권 되돌림 셋업은 타깃 거리가 짧음. 경직된 2R 요구는 대부분 미도달 → 승률 저하. 1.5R 후 본전 이동은 "최악의 경우 손실 0"을 보장 → 멘탈 보호.
- **박스 상단은 보조 지표**: 익절의 직접 트리거가 아니라 R:R 필터(§4.2)용으로만 사용. 기하 시나리오(구름·박스 상대 위치)에 로직이 의존하지 않음.
- **왜 전환선 트레일링**: 단기 추세 이탈을 민감하게 포착. 상승 추세 연장되면 잔여 20%로 큰 수익 가능.

### 4.5 분할 매집 — 2회차 (피라미딩 없음)
| 회차 | 조건 | 비중 |
|---|---|---|
| 1차 | 첫 구름 상단 터치 시 | 60% |
| 2차 | 1차 이후 양봉 확인 + 박스 중간 회복 시 | 40% |

**원칙**:
- 총 포지션은 2회차로 완성 (Phase 2는 박스권 내 지지 반등 셋업이므로 피라미딩 부적합)
- **손절가 아래로는 추가 매수 절대 금지** (물타기 금지)
- 박스 상단 돌파 후는 **익절 영역**(§4.4) — 추가 매수 로직 없음
- 박스 돌파 후 풀백 매수는 **Phase 3 Hybrid의 순차형 셋업**으로 별도 처리 (중복 방지)

### 4.6 백테스트 명세
- Phase 1과 동일한 유니버스·기간·비용 구조
- 특이점: 셋업 빈도가 Phase 1보다 낮을 것으로 예상
- 샘플 부족 시 유니버스 확대 (S&P 500 → Russell 1000)

## 5. Phase 3: Hybrid (Phase 1·2 결과 기반)

Phase 1·2 완료 후 설계. 비교 지표:
- 승률, Profit Factor, Sharpe, 최대 낙폭, 트레이드 빈도
- 두 셋업의 **시그널 상관도** (동시 발동 여부)

가능한 설계:
- **순차형** (유력): 박스권 구름 상단 지지에서 시험 진입(30%) → 박스 상단 돌파 풀백에서 본 진입(70%)
- **합집합형**: 둘 중 하나라도 시그널 발동 시 진입 (빈도↑, 승률↓)
- **교집합형**: 둘 다 발동해야 진입 (빈도↓, 승률↑)

## 6. Phase 4: Factor Stacking

Phase 3 확정 후 다음 Confluence 필터 추가:
- **모멘텀**: 3개월 수익률 상위 30%
- **변동성 수축**: 볼린저 밴드 폭 20일 하위 20%
- **상대강도**: 종목 vs 섹터 ETF 상대수익률 상위 40%

각 필터를 on/off 하며 기여도 측정 → 최종 조합 결정.

## 8. 백테스트 방법론

### 8.1 데이터 위생
- Lookahead bias 제거 (t시점 진입 시 t 종가까지만 사용)
- Survivorship bias: 현재 S&P 500 구성 사용 시 주의사항 명시, 가능하면 당시 구성 복원
- 배당 조정 종가 사용

### 8.2 검증 절차
1. **In-sample 백테스트** — 전체 기간으로 1차 파라미터 탐색
2. **Walk-Forward Optimization** — 3년 학습 + 1년 실전 롤링
3. **Monte Carlo** — 트레이드 순서 무작위화 1000회, 최악 낙폭 분포
4. **Out-of-sample** — 최근 2년 별도 검증
5. **페이퍼 트레이딩** — 실데이터 실시간 4주
6. **실전 (소액)** — 총자본 5%로 4~8주
7. **본격 운용** — 위 6단계 모두 통과 시

### 8.3 과적합 방지
- WFO 성과 ≥ In-sample 성과 × 50% 일 때만 통과
- 파라미터 변경 시 로그 필수 (무엇을 왜 바꿨는지)
- "좋은 결과 나올 때까지 튜닝" 금지

### 8.4 평가 지표
- 승률, Profit Factor, 평균 R-배수
- Sharpe, Sortino, Calmar
- 최대 낙폭(MDD), 낙폭 지속 기간
- 연도별·섹터별 성과 breakdown
