## 3. 2026-11-12 변경 (이번 세션, **미커밋** — 5장 1번)

### SPY 벤치마크 (`live_trading/risk_guard.py`, `scheduler/daily_close.py`, `scheduler/summary.py`)
- `nav_live_us.csv` 에 `spy` 열 추가. 각 행에 "그 기록이 반영한 세션"의 SPY 수정종가(배당 포함)를 붙인다.
  행 날짜는 실행일(KST)이라 직전 NYSE 세션 종가를 쓴다 (월요일 행 = 금요일 세션).
- 매 실행마다 전 행을 다시 채운다 → 과거 행(10/20~)은 다음 daily_close 에서 자동으로 채워짐.
  SPY 데이터가 방금 마감한 세션까지 안 와 있으면 오늘 행만 비워 두고 다음 실행에서 채운다.
- 텔레그램(06:30 장마감, 07:00 요약)에 한 줄 추가:
  `📊 SPY 대비 (10/20~, N일): 계좌 x% vs SPY y% → 🟢/🔴 z%p | MDD a% vs b%`
- 수동 실행: `python -m live_trading.risk_guard --benchmark` (SPY 채우고 비교 출력)
- 갱신 실패는 경고 로그만 남기고 매매에는 영향 없음.

### 기타
- **Clenow/Weinstein 페이퍼 현금 음수** (`run_daily.py`): 슬롯당 고정액을 현금 확인 없이 사던 것 →
  가용 현금(초기자본 − 보유 원가 + 확정손익) 한도 내에서만 매수. 현금이 슬롯 금액의 50% 미만이면 그 슬롯은 비워 둔다.
  과거 NAV 는 재계산하지 않음 (음수였던 기간의 페이퍼 수익률은 소폭 과대인 채로 남음).

- `summary.py` 도 파일 로그를 남긴다 (`logs/summary_*.log`).
